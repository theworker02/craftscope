# craftscope

Craft config/scope key checks for twelve-factor services.

**Site:** https://theworker02.github.io/craftscope/

## Install / run

```bash
git clone https://github.com/theworker02/craftscope.git
cd craftscope
node src/cli.js
node --test
```
